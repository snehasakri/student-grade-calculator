

\# Student Grade Calculator



A simple Java project that calculates the total marks,

percentage, and grade of a student.



\## Features

\- Accepts marks of three subjects

\- Calculates total marks

\- Calculates percentage

\- Displays the student's grade



\## Technologies Used

\- Java

\- Git

\- GitHub



\## How to Run



Compile the program:



&#x20;   javac StudentGradeCalculator.java



Run the program:



&#x20;   java StudentGradeCalculator



\## Grading System

\- A: 75% and above

\- B: 60% to below 75%

\- C: 50% to below 60%

\- D: 40% to below 50%

\- F: Below 40%
